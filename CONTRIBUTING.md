# Contributing Guidelines

## Commit Message Format
Мы используем стандарт Conventional Commits. Каждый коммит должен выглядеть так:
`<type>: <description>`

### Допустимые типы (types):
- `feat`: Новая функция (например, `feat: add division functionality`)
- `fix`: Исправление ошибки (например, `fix: solve zero division crash`)
- `docs`: Изменения в документации (`CHANGELOG.md`, `README.md`)
